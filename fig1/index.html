About this Figure

The figure above (Fig1_guetzli.jpg) was generated using the Python scripts and demo .jpg files provided in this fig1 directory.

Prerequisites

This program is highly optimized for and strictly requires Mediapipe version 0.10.21. Using other versions may cause model malfunctions or output mismatches. Please install the exact version using the command below before running the script:

pip3 install mediapipe==0.10.21

Usage

Once the requirements are met, you can generate the figure by simply executing the following command in your terminal:

python fig1.py
